# Operations: UAN

Definição dos processos operacionais do módulo de UAN.

## Core Processes

### 1. Planejamento de Cardápio
- Entrada: Grade de refeições, metas nutricionais e orçamento.
- Processo: Invocação do solver NSGA-II via Edge Function.
- Saída: Proposta de cardápio otimizado.

### 2. Gestão de Fichas Técnicas
- Cadastro de insumos e rendimentos.
- Cálculo de custo por porção.
- Padronização de processos de cocção.
