# Indústria Domain

Este documento descreve as entidades e o domínio central do módulo de Indústria.

## Entidades Principais

- **Ficha Técnica Industrial**: Receituário focado em rotulagem e GxP.
- **Ordem de Produção**: Gerenciamento da execução fabril.
- **Setor de Produção**: Unidades operacionais de trabalho.
