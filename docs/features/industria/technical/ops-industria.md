# Indústria Operations

Este documento descreve as operações técnicas do módulo de Indústria.

## Operações Principais

- **Cálculo de Receita**: Processamento de custos e rendimentos industriais.
- **Gestão de Ordens de Produção**: Emissão, acompanhamento e finalização de OPs.
- **Requisição de Materiais**: Automatização da baixa de insumos para produção.
