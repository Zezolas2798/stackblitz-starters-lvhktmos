# Especificação Técnica: Lei 10.674/2003 (Glúten)

Regulamenta a obrigatoriedade de informar a presença de glúten como medida preventiva para a doença celíaca.

## 1. Lógica de Exibição Suffix

Diferente de outros alertas, a declaração de glúten é **sempre presente** (binária).

| Condição | Frase de Saída (Obrigatória) |
| :--- | :--- |
| Contém Trigo, Aveia, Centeio, Cevada ou Malte | **CONTÉM GLÚTEN** |
| Lista de ingredientes livre de cereais e derivados | **NÃO CONTÉM GLÚTEN** |

## 2. Travas de Engenharia (Back-end)

### 2.1. Gatilhos Automáticos
O sistema deve injetar `has_gluten = true` se encontrar as seguintes strings (case insensitive) na lista de ingredientes:
-   `trigo`
-   `aveia`
-   `cevada`
-   `centeio`
-   `malte`
-   `extrato de malte`
-   `farinha de trigo`

### 2.2. Contaminação Cruzada
-   Se o alerta de alergênicos contiver "PODE CONTER TRIGO" (ou outros cereais citados), a flag de glúten deve ser forçada para **TRUE**.

## 3. Padrões de Layout

Conforme RDC 727/2022 (Integração):

-   **Posicionamento:** Logo após a declaração de alergênicos e lactose.
-   **Sequência Final:**
    1.  Lista de Ingredientes.
    2.  Alertas de Alergênicos ("ALÉRGICOS: CONTÉM...", "PODE CONTER...").
    3.  Alerta de Lactose ("CONTÉM LACTOSE").
    4.  **Alerta de Glúten ("CONTÉM GLÚTEN" / "NÃO CONTÉM GLÚTEN").**

### Formatação:
-   **Caracteres:** Negrito, caixa alta, nítidos.
-   **Contraste:** Elevado com o fundo da embalagem.
