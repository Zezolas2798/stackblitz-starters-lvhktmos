# Especificação Técnica: RDC 54/2012 - Alegações Nutricionais (INC)

Esta documentação define as regras de engenharia para o motor de cálculos de INC (Informação Nutricional Complementar) e a lógica de conformidade de layout para rótulos.

## 1. Regras de Ouro (Compliance de Fluxo)

> [!IMPORTANT]
> **Interação com a Lupa Frontal (Front-of-Pack - FOP):**
> 1. **Proibição Absoluta:** É proibida a declaração de INC para nutrientes que possuam a Lupa (ex: se o produto é "Alto em Sódio", ele não pode alegar "Baixo Sódio" ou "Menos Sódio").
> 2. **Restrição de Posicionamento:** Caso o produto possua **QUALQUER** lupa, a INC (mesmo de outros nutrientes) **NÃO PODE** estar localizada na metade superior do Painel Principal.

> [!CAUTION]
> **Qualidade Proteica (Item 2.1):** Alegações de Proteína exigem que o alimento tenha um **Escore de Aminoácidos** adequado. O sistema deve validar os aminoácidos essenciais (Anexo XXI IN 75).

## 3. Lógica de Cálculo "Duas Vias" (Art. 3.3)

O motor de cálculo deve aplicar filtros diferentes dependendo do atributo:

1.  **Cálculo no Produto Seco/Tal Qual (Modo A):**
    - Aplicável a: **Fonte** e **Alto Teor**.
    - Ignorar ingredientes adicionados (ex: leite/água de preparo).
2.  **Cálculo no Produto Preparado (Modo B):**
    - Aplicável a: **Baixo**, **Muito Baixo**, **Não Contém** e **Sem Adição**.
    - **Obrigatório** considerar contribuição nutricional dos ingredientes adicionados conforme instruções de preparo do rótulo.

---

## 4. Vitaminas e Minerais (Item 5.1)

Critérios baseados no VDR (Valor Diário de Referência) por porção:

*   **Fonte:** $\ge 15\%$ do VDR por porção.
    *   **Exceção Bebidas:** $\ge 7.5\%$ do VDR por 100ml.
*   **Alto Teor / Rico:** $\ge 30\%$ do VDR por porção.
    *   **Exceção Bebidas:** $\ge 15\%$ do VDR por 100ml.

## 5. Alegações Comparativas (Item 5.2 - Light, Reduzido)

Para utilizar termos como "Reduzido", "Light" ou "Aumentado":

1.  **Diferença Percentual:** Redução/Aumento de pelo menos **25%** no conteúdo comparado ao alimento de referência.
2.  **Diferença Absoluta Mínima (Mandatório):**
    - **V. Energético:** 40 kcal/100g (sólido) ou 20 kcal/100ml (líquido).
    - **Gorduras/Açúcares:** 1,5g/100g (sólido) ou 0,75g/100ml (líquido).
    - **Sódio:** 0,15g (sólido) ou 0,075g (líquido).
    - **Fibras/Proteína:** Mínimo de 10% do VDR por porção.
3.  **Referência:** Deve-se indicar o alimento comparado (média de mercado ou versão anterior).

## 5. Dicionário de Termos Autorizados

| Atributo | Sinônimos Permitidos |
| :--- | :--- |
| **Baixo** | Pouco, Baixo Teor, Leve (Exceto para gorduras). |
| **Não Contém** | Livre, Zero, Isento, Sem, Isento de. |
| **Fonte** | Contém, Com. |
| **Alto Teor** | Rico, Excelente Fonte. |

## 6. Lógica de Implementação no Sistema

### Motor de Cálculo (Backend)
```typescript
// Pseudocódigo de Validação (O sistema já detecta o conflito matemático)
if (lupa.alto_em_sodio && (alegacao.nutriente === 'sodio')) {
  return REJEITAR_ALEGACAO; // Conflito normativo (Implementado no Edge Function)
}

if (nutriente.valor_por_100g <= limite_inc) {
  sugerir_alegacao(nutriente.termo);
}
```

### Validador de Layout (Frontend)
> [!WARNING]
> **PENDENTE NO SISTEMA:** O componente de relatórios ainda não aplica a restrição espacial.
> Abaixo a lógica sugerida para implementação:

```typescript
// Pseudocódigo de Posicionamento (Necessário implementar no componente NutritionalLabel.tsx)
const temAlgumaLupa = Object.values(receita.lupas).some(v => v === true);

if (temAlgumaLupa) {
  const incPosition = getPosition('INC_BLOCK');
  if (incPosition.verticalIndex < totalHeight / 2) {
    mover_para_baixo('INC_BLOCK');
    alert("Layout ajustado: Alegações nutricionais movidas para a metade inferior devido à presença de Lupa.");
  }
}
```

## 7. Proibições e Travas de Categoria (Item 1.5)

O sistema deve **bloquear** a seleção de INC para as categorias:
1.  **Bebidas Alcoólicas**.
2.  **Aditivos e Coadjuvantes**.
3.  **Especiarias**.
4.  **Vinagres**.
5.  **Café/Chá/Erva-mate puros** (sem adição de outros ingredientes nutricionais).

## 8. Design e Disclaimers de Natureza (Art. 3.7)

Alegações baseadas em características inerentes ao alimento (ex: "Óleo sem Colesterol") exigem:
*   **Frase:** "Como todo [alimento], não contém [nutriente]".
*   **Regra de Fonte:** O disclaimer deve ter **pelo menos 50%** do tamanho da fonte da alegação principal.
*   **Visibilidade:** Cor contrastante e mesma tipografia.
